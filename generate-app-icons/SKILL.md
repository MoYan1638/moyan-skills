# App 图标生成生产线（Generate App Icons）

产出一张在 **29px 设置列表里依然可辨认**的图标母版，并交付 iOS / Android 双平台导出。

融合四个开源技能的设计纪律（文末致谢）：原五步流程（意象→配色→风格→生成→细节调整）保留，硬性设计规则作为约束嵌入对应步骤。

## 执行流程

### 1. 意象提取

- 用「**物体 + 动作 + 情绪**」三要素提炼产品心智，而不是只挑一个名词：
  - 日记类：日记本（物体）+ 翻开/书写（动作）+ 温暖私密（情绪）
  - 记账类：账本/硬币（物体）+ 记一笔（动作）+ 安心（情绪）
  - 待办类：列表/打勾（物体）+ 划掉一项（动作）+ 轻松（情绪）
  - 陪伴/社交类：气泡（物体）+ 说一句话（动作）+ 心意（情绪）
- 抽象意象可用（初升的太阳、色块、剪影），但意义必须由产品定位赋予，交付时说明这条心智。
- **一次只放一个主导符号**。避免通用陈词滥调（齿轮、闪电、大脑、云朵、爱心泛滥），除非它确实承载产品含义。

### 2. 主题色选择（三色纪律）

- 推荐工具：Color Hunt（现成色卡复制色号）、Coolors（空格随机直到满意）。准备 1–3 组主题色，记录色号。
- **全图恰好三色**：前景主体一色 + 可选强调细节一色 + 背景一色。强调细节复用前景色的邻近深浅不算新增语义色。
- 背景默认轻微降饱和的实底色（具名色彩对生图模型响应更好）；允许同色系明度差 ≤8% 的对角微渐变，禁止双色渐变、光斑、晕影。
- 前景与背景必须有明确的明度或色相分离；分离不足时**先调前景色，不要换背景**。

### 3. 风格确定（四条视觉路线，一次只选一条）

| 路线 | 画面特点 | 适合 |
|------|---------|------|
| 扁平描边角色 | 大色块、粗轮廓、鲜明表情 | 社区、教育、生活工具 |
| 软 3D 物件 | 圆润体积、统一材质光源 | 效率、健康、消费级 |
| 渐变剪影 | 大轮廓、受控渐变、极少细节 | 音乐、创作、情绪娱乐 |
| 极简立体符号 | 几何构形、浅浮雕、强明暗 | 专业工具、开发者产品 |

- 不把多条风格揉进同一个图标。选参考风格时同样遵循「元素单一、主体突出」。

### 4. 图标生成（构图硬约束）

- **主体占画布 62–72%**，居中，四周留呼吸边距，任何极端遮罩都裁不到主体。
- **复杂度预算：3–5 个大型基本形状**构成唯一符号；每个形状在 32×32 下独立可见，否则合并或删除。
- 至多一个识别特征；面部最多两只眼睛，必要时一张极小的嘴。
- 禁止：文字与字母（模型必然写错）、细线、锐角尖端、渐变描边、投影、拟物材质、设备样机元素。
- 尺寸 1:1，请求 1024 或更高；多分辨率由工具链缩切，**绝不要求模型直接生成小尺寸**。
- 抽卡策略：同一方向生成多个变体对比（配色轮换、轮廓微调）；一次任务交付 **3 个真正不同的方向**（在隐喻、轮廓或记忆点上不同，而不是只换颜色），并推荐其一。

**提示词骨架**（替换占位符后使用）：

```
创作一张完整的满幅 1:1 正方形图像。
背景：整个正方形填充纯粹的<背景色>，允许几乎不可察觉的同色系对角明度微变，无纹理、无晕影、无光照变化。
主体：在画面正中绘制一个极度简化的<意象>图形符号，归纳为柔和圆润的连续剪影和一个定义性特征，符号完整落在中央直径约三分之二的区域内，四周留出均匀呼吸边距。
复杂度：只用 3–5 个大型基本形状。去除一切非必要线条、轮廓线、解剖细节、纹理和装饰，保证 32×32 下依然可辨认。
色彩行为：全图恰好三种语义色。前景组织成宽大平整的色块，与背景保持清晰的明度或色相分离。面部至多两只简单的眼睛。
风格：<选定的视觉路线描述>。一切尖端以圆头结束。
约束：不要任何文字、字母、数字和水印。不加边框、相框、圆角遮罩、手机、屏幕或任何界面元素。只有一个主体符号，没有场景、没有额外物体。不做写实材质、强浮雕、光泽高光、挤压立体、强烈三维渲染和外投阴影。
```

**用途隐藏技巧**：生成提示词只描述「满幅方底上的居中图形」，绝不出现 app icon、图标、桌面、UI 等词——一旦提及，模型会画出手机主屏样机、带边框的图标卡片或拟物按钮，而不是图形本身。（只约束生成提示词，与用户对话不受限。）

### 5. 细节调整与小尺寸验收

- 生成后添加圆角、去除水印（AI 图右下角常带水印：同色区镜像补丁 + 羽化 alpha 可无痕清除）。
- 消除笔去多余文字，抠图工具提取主体。
- **小尺寸验收（不可跳过）**：把候选缩到 1024 / 180 / 60 / 32 各看一眼——轮廓是否还在、颜色是否还能区分、细节是否糊成一片。这是唯一无法代劳的人工验收。
- 评审维度：产品含义、轮廓（剪影测试：缩成纯黑剪影还认得出吗）、原创性、配色、材质、平台适配；每轮集中修 1–2 个弱项，不要全图推翻。

## 平台硬约束

- **iOS / App Store**：1024×1024、直角、无透明通道（系统自动施加圆角遮罩，不要在图里自己画圆角）。
- **Android 自适应图标**：前景主体完整落在中央约 66% 直径的安全圆内（四角会被圆形/方圆/squircle 任意遮罩裁掉）；分层交付前景 + 背景。
- 多分辨率导出（mipmap-mdpi→xxxhdpi、iOS 20–1024pt 组）由脚本从母版缩切完成。

## 输出要求

- 图标母版 + 各平台导出
- 交付清单：方向名与产品心智、提示词与三色映射、保存路径、小尺寸验收结论
- 可按评审维度继续迭代
