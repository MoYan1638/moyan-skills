# idea-to-code 从 0 到 1 开发全流程

> 🧩 本 skill 是 [MoYan1638/moyan-skills](https://github.com/MoYan1638/moyan-skills) 系列的一员，更多 skill 看那边。

AI 软件开发全流程**七步法**（适用于所有类型的软件/APP/小程序/网站/工具）：需求分析 → 低保真原型 → 概要设计 → 高保真原型 → 详细设计 → UI 设计 → 编码。

核心原则：**前 6 步定清楚才许写代码**。AI 直接写代码的默认结局是写到一半发现逻辑冲突、反复推翻重来——根因是没想清楚就动手。每一步产出书面文档供用户确认，出问题回退上一步，全程可追溯。

## 两条铁律

1. 禁止跳过前六步直接写代码
2. 思路由用户明确，AI 只负责引导与执行——AI 能帮你写代码，但帮不了你想清楚

## 七步速览（附 30 秒选档）

**先选档再开工**：正式产品走完整七步；单页小工具/个人脚本走 Lite 档（七步合并为 需求→设计→编码 三份文档，仍禁止无文档写代码）。

1. **需求分析** —— 引导提问清单把"我想做个 APP"拆成功能清单 + 用户角色 + 使用场景，明确"不做什么"防范围膨胀
2. **低保真原型** —— 线框图只验证逻辑：页面够不够、跳转通不通、入口找不找得到，丑是特性不是缺陷
3. **概要设计** —— 七步中最重要：模块划分、数据流转、技术选型（给理由由用户拍板），拿图能答"做 X 改哪几个模块"
4. **高保真原型** —— 补交互细节：每页四态（加载/空/错误/成功）缺一不可，核心业务流程从头演到尾无卡点
5. **详细设计** —— 表结构 DDL 级 + 接口入参出参错误码 + 每个功能的分支与边界，换个人只看文档就能写代码
6. **UI 设计** —— 配色/字体/图标/风格基准词，不同页面放一起是"一个软件"
7. **编码** —— 代码与设计完全一致，发现冲突停下来改文档而非"顺手改了"，产出完整项目 + 部署/使用说明

每步附通过标准与常见翻车对照表（逻辑矛盾、流程走不通、成品不符预期、字段不一致等 6 类翻车的根因与对应工序）。

与其他 skill 分工：编码完成后上生产用 `demo-to-prod`（本 skill 管想法→代码，它管代码→敢上线）、发布用 `github-publisher`、提审用 `app-review-checklist`。
