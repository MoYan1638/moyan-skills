选型口诀：能拿真实进度 → Progress · 不知耗时局部等待 → Spinner · 整页首屏 → Skeleton · 对话生成中 → Typing。禁止假进度、禁止叠加 loading、加载中必须锁交互。

① Spinner 转圈 按钮内嵌 · 锁交互

不知道耗时、局部小区域等待。提交期间按钮禁用，阻止重复点击；旁边是点状变体。
24px / 2px 环形 点状变体

② Progress 进度条 仅限真实进度

高 4px 圆角条 + 右侧百分比，完成后过渡到满条再消失。演示里的进度是模拟的——真实场景必须绑定上传/导出的真实回调，禁止定时器匀速造假。顶部还有 NProgress 风格的全局细条（模拟路由切换）。

④ Typing 三点指示器 仅对话场景

AI 开始输出文字后立刻移除，不做通用接口加载。

⑤ 与弹出层搭配 popup-layer 组合拳
