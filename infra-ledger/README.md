# infra-ledger 基建台账

> 🧩 本 skill 是 [MoYan1638/moyan-skills](https://github.com/MoYan1638/moyan-skills) 系列的一员，更多 skill 看那边。

数字资产登记与查询的 Agent Skill。"我的东西部署在哪、怎么进、什么时候到期"——这类问题一年问几次，每次都要重新翻聊天记录半天。台账趁早建，资产变动顺手记一行，之后一问即答。

## 台账覆盖

- **域名**：DNS 托管在哪、证书类型、到期日
- **服务器**：IP、进入方式（ssh 密钥路径）、跑了什么服务
- **映射关系**：哪个子域名指向哪台机哪个服务
- **账号资产**：小程序/云平台账号的主体与用途

## 使用规则

1. **查询即答**：读台账直接回答，标注信息最后更新时间，不现场重新侦查
2. **变更即登记**：谈到新域名/新服务器/新证书/迁移部署，完成时主动记一笔
3. **到期预警**：任何条目距到期 ≤30 天主动提醒
4. **敏感信息安全**：只记密钥文件路径和密码存放位置，绝不记密钥/密码本体
5. **查不到先告知**，侦查出答案后顺手补录

## 台账格式（Markdown 表格）

```markdown
## 域名
| 域名 | DNS 托管 | 证书 | 到期 | 备注 |

## 服务器
| 名称 | IP | 进入方式 | 跑的服务 | 备注 |

## 映射关系
| 子域名/路径 | 指向 | 说明 |
```

## 什么时候建

现在就建，门槛最低的时候：资产 1 个域名 + 1 台服务器时建好，之后每加一个顺手记一行，永远不积压。等有五台服务器那天才想起建，就已经积压侦查不过来了。
