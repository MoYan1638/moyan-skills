# solo-commercial-app 单人商业级应用开发流程

> 🧩 本 skill 是 [MoYan1638/moyan-skills](https://github.com/MoYan1638/moyan-skills) 系列的一员，更多 skill 看那边。

单人结合 AI 搭建商业级应用的**十步标准化流程**：商业定位 → 需求分期 → 架构选型 → 数据库设计 → 接口契约 → 分模块开发 → 联调测试 → 安全审计 → 灰度发布 → 上线迭代。

面向真实付费用户、真实收入、真实风险的商业项目。单人 + AI 能写出能跑的代码，但商业项目死于另外三样：**范围膨胀、风险裸奔、闭门造车**——本 skill 专治这三样。

## 五条铁律

1. 优先控制范围，不追求一步到位——"锦上添花"全部进后续迭代清单
2. 数据安全和业务稳定 > 美观和附加功能
3. 分阶段交付，每阶段都有可运行版本，用可运行版本验证方向
4. 日志和监控先行——那是单人开发者唯一能"分身"的手段
5. AI 可以写代码，不能替你做商业判断——盈利模式、目标人群、风险取舍必须用户拍板

## 十步速览

1. **商业定位与可行性梳理** —— 变现方式/目标人群/竞品差异/合规风险，结论三选一："值得做 / 调整后可做 / 不建议做"（判定不宜做即流程终止，这是止损价值）
2. **需求拆解与范围划定** —— 一/二/三期迭代清单，一期 = 核心刚需最小集合；新想法一律进二期，加需求走变更评估（加什么、砍什么、工期影响）
3. **架构方案选型** —— 兼顾开发效率与扩容成本，架构图画出扩容路径（不实施但要有）；单人运维专项：密钥管理、备份策略、停机预案
4. **数据库与数据模型设计** —— 实体/关系/字段/索引/数据权限，预留扩展字段，数据生命周期与归档策略提前定，敏感字段从设计期就标记
5. **接口契约制定** —— 统一格式与错误码表，契约冻结后前后端按契约 mock 并行开发——单人+AI 提效的关键杠杆
6. **分模块开发** —— 先核心链路后周边，每模块完成即验证合入，整体始终可运行；AI 分工（推理强的做架构、代码强的做实现）写进项目文档
7. **联调与集成测试** —— 端到端全链路 + 数据一致性 + 横向越权逐接口验证 + 异常兜底 + 并发场景
8. **安全审计** —— 密钥/注入/越权/敏感数据/支付幂等/依赖漏洞六项逐条过，高危清零才放行；上线后被拖库的善后成本是自查成本的一百倍
9. **灰度发布** —— 回滚方案先演练再灰度，按 5%→20%→50%→100% 分档放流量，监控三件套在线，劣化超阈值立即回滚
10. **正式上线与持续迭代** —— 告警通路实测可达，迭代复用第二至九步小循环，备份必须试恢复，收入数据回头校验商业定位

附 10 类常见翻车对照表（做一年不上线、收入模式不成立、数据库先崩、联调天天对不上、被拖库、回滚不回去、半夜挂没人知道等）与回退规则（含"商业假设被数据证伪→回第一步止损"）。
