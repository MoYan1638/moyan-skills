# decision-loop — 决策闭环

事前参谋 → 拍板留档 → 事后复盘，一个技能覆盖决策全流程。由原 strategic-advisor、decision-journal、retrospective-advisor 三个技能合并而成。

## 结构

SKILL.md 开头有一张**流程图**和进入判断：

- **阶段一 参谋**（事前）：每轮 2-3 问摸底牌、4 条退出条件防无限盘问、行动方案五段式交付
- **阶段二 决策日志**（拍板瞬间）：语义自动触发、6 字段 30 秒留档、"为什么不是 B"硬规则、可验证预期必填
- **阶段三 复盘**（事后）：固定四问挖偏差、一页复盘卡、"一个改动"原则；自动联动日志分清"决定错"还是"执行歪"

## 何时用

- 还在比较选项 → 参谋模式
- 刚做出取舍 → 顺手记日志
- 执行结束/一周收工/项目黄了 → 复盘
