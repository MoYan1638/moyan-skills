# ui-patterns — 界面设计规范三合一

导航 · 表单 · 反馈，一个技能覆盖页面三大件。由原 feedback-ui、form-patterns、sidebar-navigation 三个技能合并而成。

## 结构

SKILL.md 开头有一张**选型总图**：拿到页面需求先定位要查哪一部分。

- **第一部分 导航**：杂乱侧边栏的诊断（层级/命名/顺序/平台四病根）、优化四步（分组→选中态→底部固定→滚动结合）、折叠组、7 条坏好对照、库映射
- **第二部分 表单**：13 种组件速查与选型树、四库组件映射、错误/帮助文字同槽替换规则、9 条硬规则、8 条坏好对照
- **第三部分 反馈**：六种弹出层选型、四种加载组件、两者搭配规则、AI 生成加载组件的提示词要点、11 条场景对照

## 何时用

设计/实现/评审任何界面时一次查询：导航怎么分组、输入用什么组件、提示怎么给、等待给用户看什么。
