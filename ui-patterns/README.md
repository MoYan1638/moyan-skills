# ui-patterns — 界面设计规范合集

导航 · 表单 · 反馈 · 质感细节 · 微交互动效 · 效果提示词库，一个技能覆盖页面三大件加细节层和视觉彩蛋。由原 feedback-ui、form-patterns、sidebar-navigation 三个技能合并而成，后并入微交互动效（按钮级）与 18 效果提示词库。

## 结构

SKILL.md 开头有一张**选型总图**：拿到页面需求先定位要查哪一部分。

- **第一部分 导航**：杂乱侧边栏的诊断（层级/命名/顺序/平台四病根）、优化四步（分组→选中态→底部固定→滚动结合）、折叠组、选中高亮动效（组内滑动/跨组淡入，View Transitions 命名法）、7 条坏好对照、库映射
- **第二部分 表单**：13 种组件速查与选型树、四库组件映射、错误/帮助文字同槽替换规则、9 条硬规则、8 条坏好对照
- **第三部分 反馈**：七种弹出层选型（含 Hover Card 悬停卡）、新手引导（漫游式引导）边界、悬停类延迟关闭规则、七种加载组件（含按钮级/页面级）、向 AI 描述加载动效的三要素法、两者搭配规则、三个加载动效配方（骨架扫光/真实进度条/模糊到清晰，含可直接粘贴的提示词）、12 条场景对照
- **第四部分 质感细节**：色阶微对比替代黑粗边框、暗色模式字重降一档、同心圆角、三行 CSS 治排版乱抖（tabular-nums / 0fr→1fr / text-wrap pretty）、水墨流式打字、IME 回车拦截、滚动跟随策略、分屏拖动防翻车、动效分性格、长文件名省略号放后缀前
- **第五部分 微交互动效（按钮级）**：四种模式选型（点赞爆粒子/提交三连变/果冻开关/长按确认）+ 可直接抄的配方（曲线、时长、粒子炸开、SVG 画线对勾、进度环 rAF 状态机）+ 5 条硬规则；完整可运行示例见 `examples/buttons-demo.html`
- **第六部分 效果提示词库**（[effects-prompts.md](effects-prompts.md)）：18 个可直接复用的 UI 效果 + AI 提示词 + 实现要点——背景氛围（极光/粒子连线/鼠标光晕）、按钮（磁吸/流光边框/水波纹）、卡片图片（毛玻璃/3D翻转/对比滑块/悬停放大/滚动堆叠）、文字（打字机/流动渐变/悬浮弹窗）、滚动导航（阅读进度条/隐藏导航栏）、数据品牌（数字滚动/无缝 Logo 墙），附提示词写法结构与选型规则
- **通用节 移动端与硬性基线**：点击区 44pt / 对比度 4.5:1 / 动态字号 / 深色模式等数字底线、生成后四项自查清单、平台差异要点（层级/和谐/一致三原则贯穿全篇）

## 何时用

设计/实现/评审任何界面时一次查询：导航怎么分组、输入用什么组件、提示怎么给、等待给用户看什么、细节怎么做出质感。
