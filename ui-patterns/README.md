# ui-patterns — 界面设计规范合集

导航 · 表单 · 反馈 · 质感细节 · 微交互动效 · 特殊控件 · 效果提示词库 · 去 AI 味精修 · 风格工艺（液态玻璃/金属卡片），一个技能覆盖页面三大件加细节层、现成控件、视觉彩蛋、已有页面的体检改造与两种完整视觉风格的生产工艺。由原 feedback-ui、form-patterns、sidebar-navigation 三个技能合并而成，后并入微交互动效（按钮级）、特殊控件八件套、18 效果提示词库、去 AI 味精修流程，v3 再并入液态玻璃与金属质感卡片两个风格工艺（模板在 templates/）。

## 结构

SKILL.md 开头有一张**选型总图**：拿到页面需求先定位要查哪一部分。

- **第一部分 导航**：杂乱侧边栏的诊断（层级/命名/顺序/平台四病根）、优化四步（分组→选中态→底部固定→滚动结合）、折叠组、选中高亮动效（组内滑动/跨组淡入，View Transitions 命名法）、7 条坏好对照、库映射
- **第二部分 表单**：13 种组件速查与选型树、四库组件映射、错误/帮助文字同槽替换规则、9 条硬规则、8 条坏好对照
- **第三部分 反馈**：七种弹出层选型（含 Hover Card 悬停卡）、新手引导（漫游式引导）边界、悬停类延迟关闭规则、七种加载组件（含按钮级/页面级）、向 AI 描述加载动效的三要素法、两者搭配规则、三个加载动效配方（骨架扫光/真实进度条/模糊到清晰，含可直接粘贴的提示词）、12 条场景对照
- **第四部分 质感细节**：色阶微对比替代黑粗边框、暗色模式字重降一档、同心圆角、三行 CSS 治排版乱抖（tabular-nums / 0fr→1fr / text-wrap pretty）、水墨流式打字、IME 回车拦截、滚动跟随策略、分屏拖动防翻车、动效分性格、长文件名省略号放后缀前
- **第五部分 微交互动效（按钮级）**：四种模式选型（点赞爆粒子/提交三连变/果冻开关/长按确认）+ 可直接抄的配方（曲线、时长、粒子炸开、SVG 画线对勾、进度环 rAF 状态机）+ 5 条硬规则；完整可运行示例见 `examples/buttons-demo.html`
- **第六部分 风格工艺一 · 液态玻璃**：五步玻璃工艺（blur 28px → saturate 170% → 叠白 → 亮边+柔光三件套 → 几何透镜折射，顺序不能乱）、折射用线性渐变位移图（中心清晰仅边缘弯，禁 feTurbulence 噪声）、叠白浓度随背景深度微调、背景三原则与三禁令、照片背景专属规则、嵌套玻璃层次法则、悬浮玻璃条规则（内容从玻璃下滚过+渐隐遮罩+胶囊圆角）、折射只有 Chrome/Edge 支持的兜底兼容方案、filter 空格串联与无头浏览器验证两大避坑；完整验证过的模板见 `templates/liquid-glass.html`（五步工艺参数勿动）
- **第七部分 风格工艺二 · 金属质感卡片**：四风格速选（冷金属/磨砂/亮面/暗色金属，按页面底色明度选）+ 同心圆角算法（内层=外层−内边距）+ 四层质感结构（缺一层变纸板）+ 磨砂噪点正确写法（::before 承载/overlay/120px，禁塞 background 简写）+ 三态交互与五条禁令；完整模板与演示见 `templates/metal-card-demo.html`
- **配套一 特殊控件八件套**（[special-controls.md](special-controls.md)）：徽标 / 数字输入框（步进器）/ 时间轴 / 翻页器 / 边框流光 / 骨架屏 / 开关 / 走马灯，每个控件给选型、硬性规则、坏↔好对照和可抄参数（徽标 99+ 封顶、步进器长按加速、翻页超 7 页折叠、流光每屏 ≤2 且尊重 reduced-motion、骨架 3–4s 兜底、异步开关失败回弹）；八控件全交互示例见 `examples/special-controls-demo.html`
- **配套二 效果决策与提示词库**（[effects-prompts.md](effects-prompts.md)）：决策流程（先问场景→给选择题不问开放题→确认移动端/幅度约束→动手）+ 场景→推荐效果决策表（科技首页/落地页/作品集/长文/转化页/工具后台各该用什么避免什么）；18 个效果 + AI 提示词 + 实现要点——背景氛围（极光/粒子连线/鼠标光晕）、按钮（磁吸/流光边框/水波纹）、卡片图片（毛玻璃/3D翻转/对比滑块/悬停放大/滚动堆叠）、文字（打字机/流动渐变/悬浮弹窗）、滚动导航（阅读进度条/隐藏导航栏）、数据品牌（数字滚动/无缝 Logo 墙）
- **配套三 消除 AI 味**（[ai-taste-refine.md](ai-taste-refine.md)）：8 项 AI 味扫描（渐变滥用/发光/Emoji图标/满配圆角阴影/间距杂值/层级缺失/配色超限/动效普惠）+ 诊断报告模板 + 九刀精修顺序（层级→间距→配色→图标→圆角阴影→文案→字体→动效→硬底线）+ 改动纪律 + 五个“什么不该做” + 验收 5 问
- **通用节 移动端与硬性基线**：点击区 44pt / 对比度 4.5:1 / 动态字号 / 深色模式等数字底线、生成后四项自查清单、平台差异要点（层级/和谐/一致三原则贯穿全篇）

## 何时用

设计/实现/评审任何界面时一次查询：导航怎么分组、输入用什么组件、提示怎么给、等待给用户看什么、角标和分页这类现成控件怎么配、细节怎么做出质感、要液态玻璃或金属质感风格时照工艺走。
