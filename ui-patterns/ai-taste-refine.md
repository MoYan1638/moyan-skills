# 消除 AI 味：诊断与精修

给一个「能跑但一眼 AI」的页面做体检和整容。**先诊断后动手，按影响大小排序改**——不要一上来就替换颜色字面量。

> 本节方法参考并扩展自 Damir Sokolovsky 的 [unslop](https://github.com/heydamir/unslop)（CC BY 4.0），在此基础上补了中文界面与国内产品的判断。

## 零、先记住五句话

1. **AI 味不是「丑」，是「没有判断」**：所有元素同等醒目、所有间距是默认值、所有颜色是库默认色、所有动效都用同一个曲线。视觉上表现为注意力没有落点。
2. **改的是设计决策，不是字面量**：`linear-gradient(blue, purple)` 换成另一条渐变不算修好，要判断「这个页面该不该有大面积渐变」。
3. **去除 AI 味只做了一半**：干净但「换成任何产品名都成立」的页面，是下一版模板。**每轮必须落一个只有这个产品才有的方向 + 签名细节**（见第二节）。这是「能用」到「好用」的分界线。
4. **丰富度去对地方**：AI 味把颜色和效果摊在**外壳**上（背景、按钮、边框、标签）；有质感的设计把**外壳压安静**，把丰富度集中到**一两个内容亮点**上（渲染出来的产品图、一张真正好看的图表、产品世界里的一件实物）。
5. **不要为了去 AI 味而加装饰**：拿不准时**加留白、减元素**，而不是加阴影、加渐变、加动画。二次 AI 味最典型的来源就是「用更多效果掩盖廉价感」，换趋势（玻璃/噪点/霓虹/bento 网格）等于换一种 AI 味。

## 一、体检：8 项 AI 味扫描

对每个 HTML/CSS 文件（或页面截图）跑一遍，每项给 **命中 / 未命中 + 证据（文件:行号）+ 严重度**。

| # | 检查项 | 怎么判（可脚本化） | 严重度 |
|---|---|---|---|
| 1 | **彩色渐变滥用** | 搜 `linear-gradient` / `radial-gradient` 的用法数；页面主色块、按钮、标题、背景都用渐变 → 命中。只允许**一处**装饰性渐变 | 高 |
| 2 | **发光 / 霓虹** | `box-shadow` 里带高饱和色且 blur 大（如 `0 0 20px #7c3aed`）、`text-shadow` 发光、`filter: drop-shadow` 彩色光晕 | 高 |
| 3 | **Emoji 当图标** | 统计 `[\u{1F300}-\u{1FAFF}]`、`✅ ✨ 🚀 💡 ⚡` 等；**出现在标题/按钮/导航/功能卡片**（而非正文聊天内容）即命中 | 高 |
| 4 | **满配圆角 + 满配阴影** | 所有容器都用 `border-radius` ≥16px 或 `50%`；所有卡片都带 `0 4px 12px rgba(0,0,0,.1)` 类阴影 | 中 |
| 5 | **间距没有节奏** | 抽 `margin/padding/gap` 的 px 值，去重后是否集中在 4/8/12/16/24/32；出现 `3px 5px 7px 10px 13px 15px` 这类杂值 → 命中 | 中 |
| 6 | **字重/字号同一档** | 标题和正文都 400 或都 700；字号只有 14/16 两档没有层级跳跃 | 中 |
| 7 | **配色超出 1 主 1 辅** | 主色以外的高饱和色 ≥3 种；或出现 `#ff0000 #00ff00 #0000ff` 纯色 | 中 |
| 8 | **动效普惠化** | `transition: all` 全站使用、时长 ≥0.4s、hover 位移/缩放用在所有卡片上 | 低~中 |

**脚本化建议**：与其写一个脆弱的正则替换器，不如让 AI 直接读文件做语义判断——正则能可靠做的是**计数**（渐变数、emoji 数、颜色种类数、间距取值集合），判断交给模型。批量文件时先跑计数，列出「最像 AI 的 3 个文件」优先改。

### 补充扫描项（主表 8 项之外的高频特征）

| 特征 | 判据 | 为什么算 AI 味 |
|---|---|---|
| 渐变文字 | 标题/数字/logo 用 `background-clip: text` + 渐变 | 一眼胎记，且牺牲可读性 |
| 大写 + 宽字距小标签 | `text-transform: uppercase; letter-spacing: .1em` 的 `NAVIGATION` 类小标 | 假装高级的模板手法 |
| 字重 800/900 堆标题 | 标题全用 `font-weight: 800+` | 用粗细代替字号做层级 |
| 胶囊泛滥 | 搜索框、按钮、卡片全是全圆角 pill | 不区分控件类型 |
| 徽标/角标泛滥 | `PRO` `New ✨` `Beta 🚀` 贴满 | 装饰性噪音 |
| 假大空文案 | 「Welcome back 👋」「Supercharge your workflow」「一站式赋能」 | 空词 + 问候式大标题 |
| 数据不成形 | `$48,210` 和 `$124,860.40` 混排、变化量写 `+12%!!` 无基准 | 数字没有统一格式与参照 |
| 首屏堆叠居中 | 徽标→标题→两行副标题→三个按钮→头像列表→评分星 | 典型落地页模板骨架 |
| 玻璃卡 + 白色高光 + 彩色阴影 | 半透明卡上刻意打一圈白边高光 | 假玻璃（真玻璃要有真实背景层次） |
| 循环动画 | `animate-pulse` / `animate-ping` / 呼吸光晕用在非实时元素上 | 动效没有语义 |
| 视觉素材假 | 发光大脑/机器人/紫色星云/液态铬球做 hero 主图 | AI 图库味，与本产品无关 |

### 诊断报告模板（直接输出给用户）

```
AI 味体检：index.html
严重度排序（改前面的收益最大）

[高] 渐变滥用 ×4：背景（L23）、主按钮（L41）、标题（L58）、卡片边框（L77）
     → 保留 1 处（建议弱化为背景微光或直接删除），按钮改实色
[高] Emoji 图标 ×9：功能卡片标题前 👉（L102/110/118…）
     → 全部换同风格 SVG 图标或直接删
[高] 发光 ×3：主按钮 0 0 24px #8b5cf6（L44）…
[中] 间距杂值：3px/5px/7px/10px/13px/15px 共 21 处 → 归到 4/8/16/24
[中] 层级缺失：h1 32px/700，h2 32px/700，正文 16px/400，h3 16px/400
结论：结构可用，视觉需重排序。预计改动 40 处，不动布局。
```

### 第 0 步：定方向（必须在动手前做，且给用户确认）

不去定方向就开始改，最后必然落到「干净但任何产品都能用」的模板。写五行，全部从这个产品本身推导，**不许用「简洁/现代/高级/极简」这类适用于一切模板的词**：

1. **产品**：它是做什么的、给谁用，一句大白话
2. **性格**：两三个具体的词，如 `冷静、精确、有一点暖` / `快、技术、爱玩`
3. **世界**：产品天然属于什么场所或材质——笔记应用靠近纸与墨，监控工具靠近仪表与夜班，旅行应用靠近地图与窗光。它决定中性色的偏色、主色和主视觉
4. **亮点区（1~2 处）**：页面里允许出现浓色、材质、细节的地方，从产品显示的东西里选（预览里的一张渲染卡片、图表里每种颜色代表一条数据、产品世界里的一件实物）。写清是哪两处
5. **签名细节（只一个）**：只有这个产品才会有的一处小细节并贯穿全站——监控工具用实时状态点，开发者工具用键帽，教学应用用手绘下划线，物流用路线线。**一个，不是五个**

已有真实品牌（logo 文件、真实主色、非 AI 味的字体）就保留，方向围绕它建；但紫蓝渐变、闪光、辉光即使用在 logo 上也仍算 AI 味，除非用户明确说这是品牌。

然后把**审计清单 + 方向**一起给用户看，等确认再动手——方向变了等于全部重做。

## 一点五、参数表（九刀的数值都在这，可直接写进提示词）

数值是起点不是风格，方向定了就跟着方向微调；项目里已有好的设计系统就沿用它的值，只修用法。

**间距阶梯**：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64 / 80 / 96 / 128
- 控件内部 4~12｜同组相邻（列表行）2~8｜组之间（标签与其列表、两张卡）12~24｜区块之间 32~64｜落地页大区块 80~128
- 行高：紧凑 32 / 默认 36 / 触屏 40~44；导航到主标题桌面 96~128、移动 48~64

**应用布局**：侧边栏 240~280，内容区页面内边距 24~32，最大宽 1440~1600；顶栏 56~64；导航行 32~36、行间距 2~4、分组标题上方 24 下方 8
- 统计卡一行等高、桌面一行 3~4 张、只放数字；主图表占内容宽 ≥2/3、高 280~360，旁边的第二块数据用列表或表格而不是第二张图

**中性色阶**（后台/仪表盘用石墨色；落地页按「世界」选偏色——暖调适合纸/木/食物/手作，墨蓝适合夜晚/天空/水/技术）
| 角色 | 暗-石墨 | 暗-暖 | 暗-墨 | 亮-石墨 | 亮-暖 | 亮-墨 |
|---|---|---|---|---|---|---|
| 最深面（侧边栏） | #0f0f10 | #12110f | #07080d | — | — | — |
| 页面底 | #141415 | #161513 | #0b0d14 | #fafafa | #f7f4ee | #f5f7fa |
| 卡片 | #19191b | #1c1a18 | #11141c | #ffffff | #fdfbf7 | #ffffff |
| 抬起/选中行/输入框 | #232325 | #262421 | #1a1e28 | #f4f4f5 | #efe9df | #eceff4 |
| 主文本 | #ededed | #efe9de | #eef0f5 | #171717 | #1f1b16 | #111827 |
| 次文本 | #a1a1a6 | #aaa398 | #a3a9b8 | #525252 | #5e554a | #4b5565 |
| 弱文本/图标 | #85858b | #8a847a | #7a8296 | #737373 | #7b7266 | #6b7487 |

分割线一律用主文本色 8% 透明度；弱文本仅用于元信息与说明、对比度保持 ~4.5:1；语义色：成功暗 #4cc38a / 亮 #16a34a，危险暗 #e5484d / 亮 #dc2626。

**主色**：有真品牌色就留；没有从「世界」里取——暖世界→琥珀/珊瑚/余烬橙，冷世界→钴蓝/青绿/晴空蓝，自然世界→苔绿/鼠尾草，**紫色到蓝色的色相渐变不算品牌色**；主色上的文字对比度要 4.5:1，不够就压暗主色或改深色文字；主色只覆盖几个百分点（主操作、选中态、一个关键数字）。

**按钮**：hero 按钮高 44~48，导航按钮 32~36，左右内边距 16~20；主按钮=暗底用色阶里的近白配深字、或主色，亮底用主文本色填充配白字、或主色；次按钮=抬起的surface+发丝线；暗底按钮可加 `inset 0 1px 0 rgba(255,255,255,.12)` 做顶部高光（有体积感但不是发光）。

**字体**（按性格选，都是免费的）：
| 性格 | 界面字体 | 可选搭档（仅大标题/数字） |
|---|---|---|
| 精确、技术、冷静 | Geist / Inter / IBM Plex Sans | Geist Mono、IBM Plex Mono、JetBrains Mono |
| 温暖、友好、有人味 | Instrument Sans / DM Sans / Figtree | Instrument Serif、Newsreader（仅 hero 标题） |
| 编辑、文学、手作 | Inter 或 Instrument Sans | Newsreader、Instrument Serif、Fraunces |
| 活泼、大胆 | Space Grotesk / Bricolage Grotesque | 一个等宽字体做小标签 |

衬线标题字体只能给大标题，绝不用于标签和按钮。中文场景：界面用「苹方/思源黑体/HarmonyOS Sans」一类无衬线，标题想有性格可选「思源宋体/霞鹜文楷」但同样只给大标题。

**字号阶梯**：小标签/元信息 12/16/400（数字可用等宽）｜次要文本 13~14/20/400｜正文与导航 14~15/20~22/400~500｜logo 16~18/500~600｜hero 副标题 18~20/28~30/400、宽度 ≤36rem｜卡片数字 28~32/1/500 + tabular｜页面标题 28~36/1.15/400~500｜hero 标题 桌面 56~72、移动 36~44，行高 1.02~1.08
- 字距：16px 以下为 0（小号弱文本可 0.01em），≥40px 可 -0.02em，≥56px 可 -0.03em

**圆角**：键帽/标签/小按钮 4~6｜行/输入框/按钮 8~10｜卡片 12~16｜面板窗口 14~20；嵌套圆角 内 = 外 − 内边距，不低于 4

**图标**：Lucide，16 或 18px，描边 1.5，颜色用弱/次文本角色，与文字间距 8~10px

**深度**：暗底靠 surface 阶梯 + 发丝线；亮底小元素 `0 1px 2px rgba(0,0,0,.05)`，浮层 `0 8px 24px rgba(0,0,0,.06)`

**动效**：全站一条曲线 `cubic-bezier(0.22, 1, 0.36, 1)`

| 用途 | 时长 |
|---|---|
| hover / press / 开关 | 120~180ms |
|---|---|
| hover / press / 开关 | 120~180ms |
| 菜单 / 气泡 / tooltip | 160~220ms |
| 入场 / sheet / 布局变化 | 300~500ms |

入场上升距离 6~12px，按下缩放 0.97~0.98；只过渡 color / background / border / opacity / transform。

## 判定改动量级（读完审计再决定改到哪一步）

- **重度 AI 味**（颜色/字体/图标/文案多处命中）：走完整九刀
- **轻度**（大体已设计、剩几个迹象）：只修审计命中的项，方向从现有品牌取，不动配色字体布局；更大的想法（缺一个亮点区、hero 要实景）写进报告作为建议，不擅自改
- **没有 AI 味**：直说，最多提 2~3 个带具体数值的小改进，用户同意再做，**绝不为了「不一样」而改好页面**

## 二、精修：按这个顺序改（收益从高到低）

**顺序不能乱**——先调层级和间距（结构层），最后才碰颜色和动效（装饰层）。反过来做等于给烂骨架刷漆。

### 第 1 刀：视觉层级（最见效）

- 一个页面**只允许一个「最响」的元素**（主 CTA 或主标题）。其余全部降一档：次要按钮从实心改描边/文字按钮，卡片标题从 700 降 600，说明文字降到中性灰
- 字号建立跳跃：正文 14~16 → 小标题 18~20 → 区块标题 24~28 → 主标题 32~40，**不要每个都差 2px**
- 字重只用 3 档（400/500/600），同屏不超过 2 档；**不用 800/900** 硬撑层级
- 拿不准的地方加留白，不要加装饰

### 第 2 刀：间距节奏

- 间距只用 `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`，杂值向上吸附到最近档
- **组内紧、组间松**：同组元素 8~12，组之间 24~32，区块之间 48~64。间距差是「分组」的视觉语言
- 容器内边距一致（卡片统一 16 或 24），不要一张 12 一张 20

### 第 3 刀：配色收敛

- 收敛到 **1 主色 + 1 辅色 + 中性灰阶**。主色取品牌色（没有就从「世界」里取：暖世界→琥珀/珊瑚/余烬橙，冷世界→钴蓝/青绿/晴空蓝，自然世界→苔绿/鼠尾草；**紫色到蓝色这个色相家族默认排除**，除非品牌真是紫）
- 大面积色块（背景、卡片、区块）用中性色或主色的极低透明度（≤8%），**不要用饱和主色铺底**
- 文本色不用纯黑（`#111827` 类深灰更耐看），次要文字用中性灰而不是降低透明度的黑色
- 只保留一处装饰性渐变，或全部删除改为纯色 + 极淡渐变（相邻色相）
- **三段文本角色**：主要 / 次要 / 弱，全部从同一条中性色阶取，不要用同一色相的五个深浅相近的紫
- **强调色一屏只用一两次**：哪里都用高亮等于没有高亮；主色只该出现主操作、选中态、一个关键数字

### 第 3.5 刀：内容亮点（让页面只属于这个产品）

这是「干净但像模板」和「有设计感」的分水岭，常被跳过：

- 每屏至少一处**真实产品的呈现**：真实数据的预览、真渲染的对象、真正好看的图表（颜色各代表一组数据），而不是空框或占位符
- 外壳（导航/按钮/标签/边框）保持安静，丰富度集中在这一两处。所有元素都抢镜 = 没有亮点
- 表单/后台类页面这一步可以很轻（一张真数据表格、一个真图表足够），落地页/首页必须做
- **挑一个能证明标题的时刻，不是整个应用**：排班工具只展示某周一个已排上的时段，代码评审工具只展示一条带评论的 diff，习惯打卡只展示一张卡的连续天数。有项目自带组件就用它，没有就用新配色写一次认真 HTML + 合理假数据 + 真名字
- **要不要生成图**：后台/设置这类页面不需要；落地页 hero 和空状态通常需要。需要时：①有图像工具就生成一张「世界里的一幕」做整幅 hero 背景，主体放一侧、另一侧留空隙给标题，产品视图从底部升起（最强的 hero）②没工具就在代码里搭产品预览，并把生成提示词写进报告
- **场景一句话**：用方向里的「世界 + 性格」把主体写成一句大白话再生成，说不成一句就说明还没想清。例：备份工具→浓雾海盼一座小灯塔的光指向远方；冥想应用→清晨窗台上一杯冒热气的茶；物流 API→平静灰海上一艘俯瞰的集装箱船
- 图像落页：导出 WebP/AVIF 两倍尺寸、写真实的 `alt`、边缘用 `mask-image: radial-gradient(closest-side, #000 70%, transparent)` 或页面色渐变淡出（硬矩形边贴在不同色底上就是 AI 味）、固定宽高防布局跳动

### 第 4 刀：图标与图形

- Emoji 全部替换为**同一套线性/面性图标**（Lucide / Material Symbols / 项目内 SVG），或直接删掉图标只留文字
- 图标统一尺寸（16/20/24 三档）和描边宽度，颜色继承文字色
- 不要给图标加彩色底圈 + 圆角方块 + 阴影三件套

### 第 5 刀：圆角与阴影统一

- 圆角定一套语义层级：输入框/小控件 8~10，卡片 12~16，面板/窗口 14~20，标签/键帽 4~6。**圆形只给头像和圆形图标按钮**；默认不要把所有东西做成胶囊
- 嵌套圆角必须相加成立：内 = 外 − 内边距（例：16px 卡片 + 8px 内边距 → 内部元素 8px），否则拐角缝隙一头宽一头窄
- 阴影只用一个层级（小元素 `0 1px 2px rgba(0,0,0,.05)`，浮层 `0 8px 24px rgba(0,0,0,.06)`），删除彩色阴影和发光
- 相邻层优先用背景色阶区分（亮度差 1%~3%），不用边框硬切；分割线用主文本色 8% 透明度

### 第 6 刀：文案

- 删掉「强大、极致、一站式、赋能、轻松实现」这类空词，改成具体事实（数字、时限、范围）
- 按钮用动词开头且**同一动作全站同名**（不要「立即体验 / 马上开始 / 快速上手」混用）
- 少用感叹号和 emoji 标点；提示语用中性语气
- 标题不要每条都带对仗短句，允许一条长一句短

### 第 7 刀：字体

- 字体栈：`system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
- 数字场景加 `font-variant-numeric: tabular-nums`
- 中文正文行高 1.6~1.75，标题 1.25~1.35；段落宽度限制在 65~75 字符（`max-width: 68ch`）
- 字重只用 400/500/600，**不用 800/900**；层级靠字号和留白，不靠加粗
- 不用大写 + 宽字距的小标签（`NAVIGATION` / `PAID THIS MONTH`）：中文没有大小写，这条主要针对英文界面，中文等效用「小一号 + 中性灰」的组标题
- 小字不要负字距，不用斜体强调（用颜色或字重）
- 数字统一一种格式：同一屏不混 `$48,210` 和 `$124,860.40`；变化量必须带基准（`+12% 环比上月` 而不是 `+12%!!`）

### 第 8 刀：动效克制

- 只给**交互反馈**加动效（hover / 点击 / 状态切换），不给静态元素加呼吸/浮动/旋转
- 全站一条缓动曲线 `cubic-bezier(0.22, 1, 0.36, 1)`，时长按用途分档（见参数表：交互 120~180ms，浮层 160~220ms，入场 300~500ms，错峰 40~60ms 最多 6 项）；需要回弹的按钮级微交互（开关、点赞）单独用弹簧曲线，见第五部分
- 入场只做「短距离上浮 + 淡入」（6~12px），按下缩放 0.97~0.98，**不做视差、不做循环漂浮**
- `transition: all` 全部改成显式属性（`transition: background-color .2s, border-color .2s`）
- 加 `@media (prefers-reduced-motion: reduce)` 关掉位移与缩放

### 第 9 刀：最后过一遍硬底线

- 正文对比度 ≥ 4.5:1，点击区 ≥ 44×44（移动端）
- 深色模式用语义色变量，不硬编码 `#fff / #000`
- 大字号（系统缩放 150%）下布局不塌

## 三、改动纪律

1. **一次只改一个维度**，改完对同一张截图对比。混着改会分不清哪步有效
2. **不改内容结构**：去 AI 味是视觉精修，不重排信息架构、不删功能入口。要动结构先跟用户确认
3. **保留原文件**：改第二刀前先把第一刀的结果存成 `xxx.refined.html`，或至少让用户能对比前后
4. **不引入依赖**：不为了图标去装图标库，用内联 SVG；不为了动效引入动画库
5. **没有截图就先截**：改前改后各截一张（桌面 + 移动），视觉类改动必须眼见为实
6. **九刀是整屏一次性过完，不是逐元素换皮**：像设计师做红笔画批，一刀横穿整个页面再进下一刀；某一刀几乎全变时可先排好顺序再一次写完页面
7. **改完必须回收对比**：把改前审计清单逐条对一遍，还留着的项补掉；最多渲染三次截图校验，别无限循环
8. **不改产品定位**：不改产品名、不改功能区与区块顺序、不编造功能/数据/宣称；占位假数据可以换成合理真数据

## 四、什么不该做（常见错误）

- ❌ 把彩色渐变换成另一组更好看的彩色渐变（病根是「大面积饱和色」，不是色号）
- ❌ 把 Emoji 换成同样花哨的 3D 插画图标（换汤不换药）
- ❌ 为了「高级」加玻璃拟态 + 大圆角 + 彩色阴影（这是另一种 AI 味，参见 liquid-glass-ui 技能：真玻璃要有真实背景层次才成立）
- ❌ 全站统一 `border-radius: 8px` 但层级全乱（圆角只是皮，层级才是骨）
- ❌ 用脚本正则批量替换颜色字面量当成「优化」（生成器式的机械修改几乎必然产出新的不一致）
- ❌ 只做「减法」：拆得干净利落但没有任何属于这个产品的亮点，等于产出了下一份模板
- ❌ 把「去 AI 味」做成改版重设：改产品名、重排区块、加新功能（那不是精修，是另一个项目，得先问）

## 五、验收：先查清单，再问 5 个问题

**硬清单（逐条过，不过不上线）**：间距全在 4px 网格且同类同尺寸 → 图标/标签/数字各自对齐成一列 → 一套中性色阶 + 三种文本角色 + 一个足够对比度的强调色 → 无彩色渐变/渐变文字/发光/彩色阴影/色斑 → 界面里零 emoji → 一套图标且单一尺寸描边 → 字重 400~600、无大写宽字距标签 → 无感叹号、无空词、无未证实宣称 → 数字格式统一 + 同宽数字 → 嵌套圆角相加成立 → 动效单一曲线、无循环漂浮、只动 transform/opacity。

**然后问 5 个问题**：

1. 眯眼看这个页面，视线第一落点是不是你希望的那个？（只有一个）
2. 截图缩到 30% 大小，还能看出分组和信息层级吗？
3. 把所有颜色转成灰度，层级还在吗？（如果不在，说明层级全靠颜色撑着）
4. 随便找两个间距值，能不能说出「为什么是它」？（说不出说明节奏是随机的）
5. 关掉所有动效，页面变难看吗？（变难看说明动效在掩盖静态问题）

**最后一道模板检查**：把产品名换成另一个产品的名字，这个页面还成立吗？如果成立，说明方向没做够——回到第 0 步，在文案、主视觉、签名细节上把方向推得更狠。

## 六、可选升级：把主视觉做成「属于这个页面的」代码效果

去 AI 味到这一步，如果页面已经有了一张真图，还能再走一步——让它在**代码里**被处理成只属于这个设计的样子。只在主视觉上用一次，别扩散成装饰。

- **字符画（glyphs）**：把图像画成字符网格，亮度决定选哪个字符。最适合字符来自产品自己材料的情况——财务/发票用 `. : 1 7 4 0 8 $ %`，代码工具用 `. : / { } < > = #`，数据/监控用 `. · : | + ▪`，音乐用音名。格 6~10px，用等宽字体，颜色取自图像或色阶；让少数格子缓慢变化就有「活的」感觉
- **半调网点（halftone）**：同网格，按亮度改变圆点半径，单一墨色印在页面底色上。适合编辑、印刷、手作气质
- **抖动（dither）**：二次色或误差扩散到色阶里 2~3 个颜色。适合复古、技术、爱玩的气质；在图片加载时算一次，不要每帧算
- **双色调（duotone）**：把亮度映射到两个颜色（色阶最深面 + 主色或主文本色），是把任意生成图拉回配色的最省事办法——CSS 里灰度图叠一层 `mix-blend-mode: color` 的主色层，或 SVG `feColorMatrix`

性能三条硬约束（这类效果最容易把老笔记本卡死）：**像素只在图片加载时读一次**（绝不在动画循环里 `getImageData`）→ 字符图集/着色块提前烘好，循环里只 `drawImage` → 每秒 8~12 步而不是 60 帧，每步只改一小部分格子；画布离屏时暂停，DPR 上限 2。

参考实现（字符画完整代码 + 性能注释）见 unslop 的 `references/effects.md`。

用 [video-pipeline](../video-pipeline) 的工序，别单独写截图脚本：截改前/改后关键屏 → ffmpeg 左右拼接或叠化 → 加标注。单纯截图转视频（等间隔截几帧再拼）出来的是幻灯片，不是演示——要动效说明就用浏览器的过渡动画真实录制。

## 改完交付什么

1. **诊断报告**：审计清单（每条带位置）+ 改动量级判定
2. **方向五行**：产品 / 性格 / 世界 / 亮点区 / 签名细节
3. **逐刀说明**：每刀改了什么、为什么（几行就够，不要写给用户看的长篇）
4. **改后页面**：独立文件，可直接交给真实站点负责人；只有链接时先落盘静态快照再改，并说明这是静态重构版
5. **可选故事视频**：要发社交平台时做成 10 秒内的方形短片，展示页面自己被「解 AI 味」的过程（Playwright 逐帧 + ffmpeg 合成）
