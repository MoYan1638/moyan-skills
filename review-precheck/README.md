# review-precheck 提审预检

> 🧩 本 skill 是 [MoYan1638/moyan-skills](https://github.com/MoYan1638/moyan-skills) 系列的一员，更多 skill 看那边。

小程序/App 提交审核前的合规检查流。提审被驳回 90% 的原因在提交之前就能查出来，每次驳回浪费 1-3 天——本 skill 在你要提审的那一刻现场执行五项检查，把驳回概率压到最低。

## 五项检查

1. **措辞红线扫描**：全文扫"咨询/疗愈/心理疏导/诊断/陪聊"等敏感词，并检查同义改写是否真的安全（"焦虑型依恋"危险 → "你在关系里习惯先观察再靠近"安全）
2. **类目匹配**：所选类目与实际功能是否一致，个人主体在该类目的允许边界
3. **功能边界**：内购支付（需企业主体）、开放式 AI 对话入口、UGC 公开区、站外导流——个人主体专属禁区逐项排查
4. **游客模式可走通**：审核员不登录能否走通核心流程，有没有"内容为空"和强制登录风险
5. **素材合规**：截图二维码、诱导分享文案、夸大宣传、蹭热词名称

## 产出判定

- ✅ **可提**：全绿直接提
- ⚠️ **改完再提**：列出具体改哪几处、改成什么措辞
- ❌ **提了也会拒**：说明根因，给替代方案

## 与一般"审核攻略文章"的区别

攻略是静态文章，这是**在提审那一刻现场执行的检查流**；且每次被驳回后把真实驳回理由按"原因→解法"沉淀进规则库，只增不删，越用越准。

## 内置背景红线（来自实战素材）

- 测试类小程序：AI 解读必须定位"趣味内容展示"，不碰"心理咨询/AI 陪聊"
- 引导式生成（固定按钮触发）安全，开放式对话高危
- "测完出结果卡片"分享安全，"分享解锁结果"属诱导分享高危
