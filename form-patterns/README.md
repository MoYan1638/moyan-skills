# form-patterns — 表单组件设计规范

13 种表单输入组件的选型与交互规则，配套 [feedback-ui](../feedback-ui)（那个管提示与反馈，这个管输入与校验）。

## 收录组件

浮动标签 / 验证码输入框 / 拖拽上传 / 日期选择器 / 滑块 / 自动补全 / 级联选择 / 标签输入 / 密码框 / 下拉选择 / 校验报错 / 帮助文字 / 必填星号

## 核心原则

1. **规则前置**：限制和要求在用户动手之前就展示（帮助文字、上传框内说明），而不是报错时才说
2. **失焦校验**：不边输边报，也不拖到提交才报；报错写修改方式，不写"格式错误"
3. **按选项数量选组件**：<5 平铺单选、5+ 下拉、多且需搜索转自动补全、有层级用级联
