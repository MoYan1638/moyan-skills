# motion-patterns 页面级交互动效八合一

提供 8 个页面级交互动效的标准化实现方案，覆盖卡片、列表、输入框、页面切换等高频场景，每个动效附物理参数基准、可直接使用的 AI 提示词、边界情况处理，帮助开发者快速实现具备真实物理手感的 App/小程序/H5 交互效果，告别模板感。

**八个动效**：卡片堆叠甩动 · 弹性下拉刷新 · 大标题滚动收缩 · 骨架屏扫光渐显 · 浮动标签与错误抖动 · 拖拽排序 · 滑动删除加撤销 · 侧滑返回视差

**每个动效包含**：动效表现 → 物理参数基准（时长/曲线/阈值三个数字，验收就核它）→ 可直接使用的 AI 提示词 → 边界情况处理。

**四块公共设施**：
- **场景速选表**——按"场景症状"一眼选对动效；选档纪律：一个页面最多 1~2 个页面级动效，只允许一个主动效焦点
- **平台实现锚点**——Android Compose / iOS SwiftUI / H5 / 小程序四端落地 API 映射（含小程序跟手动画必须写 wxs 的关键坑），禁止凭空造 API；附性能硬规则（只动 transform/opacity 合成层属性）
- **无障碍硬规则**——非颜色区分成功失败、手势动效必须保留等效非手势路径、触控目标 ≥ 44pt
- **验收清单**——六个勾选项逐项过：三数字对齐、跟手逐帧回放、连触/打断状态机不破、reduced motion 直切、无障碍、实测帧率与降级路径

**核心原则**：物理手感优先（弹簧/阻尼/视差，禁线性生硬动画，跟手阶段与手指同步）；动效服务于体验不过度设计（同屏活跃动效 ≤ 2 处）；与页面布局和业务场景深度结合、同类动效参数全局一致；可降级（尊重系统减弱动态效果，低端机掉帧自动降级为直切）。

**输出要求**：每个动效交付交互说明文档（操作方式/视觉反馈/边界情况）；多端适配保证 App/小程序/H5 表现一致，平台有原生组件优先用原生。

通用物理参数基准：微反馈 100~150ms、状态切换 180~300ms、页面转场 260~350ms，标准缓动 `cubic-bezier(.22,.8,.3,1)`，弹簧单次轻微过冲（overshoot ≤ 1.05）禁止持续振荡。

**使用方式**：对照场景选动效 → 贴「AI 提示词」给 AI → 按「物理参数基准」验收 → 按「边界情况」补齐处理。

**与其他 skill 配合**：ui-patterns 管静态界面规范、本 skill 管动态手感（先定布局再打动效）；liquid-glass-ui 提供玻璃材质下的参数微调；demo-to-prod 的体验验收维度用本 skill 的参数核对。
