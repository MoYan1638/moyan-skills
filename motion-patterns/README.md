# motion-patterns 交互动效手感全集（页面级八动效 + 控件级按钮六方案）

提供 14 个高频场景的标准化交互动效实现方案，分两部分：**A 部分·页面级动效八合一**（卡片堆叠甩动 · 弹性下拉刷新 · 大标题滚动收缩 · 骨架屏扫光渐显 · 浮动标签与错误抖动 · 拖拽排序 · 滑动删除加撤销 · 侧滑返回视差）+ **B 部分·控件级按钮六合一**（长按确认 · 点赞迸发 · 滑动确认 · 加入购物车飞入 · 主题切换扩散 · 复制反馈）。帮助开发者快速实现具备真实物理手感的 App/小程序/H5 交互效果，告别模板感与"按钮没有状态机"问题。

**每个方案包含**：动效表现 → **何时不用**（每个方案的明确不适用场景）→ 物理参数基准（时长/曲线/阈值三个数字，验收就核它）→ 可直接使用的 AI 提示词 → 边界情况处理。B 部分核心方法"按钮是状态机"：强制覆盖初始→操作中→完成→恢复四态，两态按钮=没做完。关键参数已与 ui-patterns 微互动配方对齐，二者不冲突。

**公共设施**：
- **场景速选表**——按"场景症状"一眼选对方案；选档纪律：一页最多 1~2 个页面级动效、一界面仅 1 个主行动按钮配高级动效
- **平台实现锚点**——Android Compose / iOS SwiftUI / H5 / 小程序四端落地 API 映射（含小程序跟手动画必须写 wxs 的关键坑），禁止凭空造 API；附性能硬规则（只动 transform/opacity 合成层属性）
- **无障碍硬规则**——非颜色区分完成态、结果反馈读屏播报、手势动效保留等效非手势路径、长按/滑动确认必须给替代路径、触控目标 ≥ 44pt
- **验收清单 + 配套验收提示词**——七个勾选项逐项过；实现完成后原样把验收提示词发给 AI 让它自查，缺项补齐再交付

**核心原则**：物理手感优先（弹簧/阻尼/视差，禁线性生硬动画，跟手阶段与手指同步）；全状态覆盖（B 部分硬性）；动效服务于体验不过度设计；可降级（reduced motion 直切 + 低端机掉帧降级 + 平台能力缺失静默过渡）。

**与其他 skill 配合**：ui-patterns 管静态界面规范与微互动速查配方（先定布局再打动效）；idea-to-code 的高保真原型/UI 设计步骤衔接本 skill（原型定结构、本 skill 定手感）；demo-to-prod 上线验收用本 skill 参数核对。
