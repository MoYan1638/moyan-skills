# motion-patterns · 交互动效手感全集

给 App/小程序/H5 的交互层加"真实物理手感"。**A 部分**管页面级动效（八个高频场景），**B 部分**管控件级按钮动效（六个高频方案）。所有方案共用同一套运动语言，混用依然协调。

## 使用方式

1. **先分粒度**：动的是页面/列表/转场 → 用 A 部分；动的是按钮/控件 → 用 B 部分
2. 对照场景速选表选中方案（可多个组合）
3. 把该方案的「AI 提示词」原文交给 AI
4. 按「物理参数基准」验收：时长、曲线、阈值三个数字对不上就打回
5. 交付前按「验收清单」逐项勾选

## 场景速选表

**A 部分 · 页面级：**

| 场景症状 | 用哪个动效 |
|---|---|
| 连续决策型内容（选人/选图/滑动筛选） | A1 卡片堆叠甩动 |
| 列表数据更新（feeds/消息/订单） | A2 弹性下拉刷新 |
| 详情页/层级内容页的沉浸浏览 | A3 大标题滚动收缩 |
| 接口等待超过 300ms 的加载区 | A4 骨架屏扫光渐显 |
| 表单/登录/设置里的输入框 | A5 浮动标签与错误抖动 |
| 用户可自定义顺序的列表（歌单/清单） | A6 拖拽排序 |
| 高频列表操作（删除/归档/移除） | A7 滑动删除加撤销 |
| 二级及以下页面的返回 | A8 侧滑返回视差 |

**B 部分 · 控件级：**

| 场景 | 用哪个方案 |
|---|---|
| 危险/不可逆操作（删除/支付/清空） | B1 长按确认 |
| 情感表达/状态切换（点赞/收藏/关注） | B2 点赞迸发 |
| 关键操作防误触（接单/启动/解锁） | B3 滑动确认 |
| 电商加购/收藏加入 | B4 加入购物车飞入 |
| 深浅色主题切换 | B5 主题切换扩散 |
| 复制/分享/发送等瞬时操作 | B6 复制反馈 |

**选档纪律**：A 部分一个页面最多 1~2 个页面级动效，只允许一个「主动效焦点」；B 部分一个界面只有 1 个主行动按钮配高级动效，其余按钮用统一的基础按压反馈（scale 0.97 + 120ms）。满屏都在动就没有重点，低端机性能也吃不消。

## 通用物理参数基准

所有方案遵守同一套运动语言：

| 项目 | 基准 |
|---|---|
| 微反馈（按压/悬停） | scale 0.96~0.98 + 透明度微降，100~150ms |
| 状态切换（展开/收起/补位） | 180~300ms |
| 页面级转场 | 260~350ms |
| 标准缓动 | `cubic-bezier(.22,.8,.3,1)`（快出缓停） |
| 弹簧/回弹 | `cubic-bezier(.34,1.56,.64,1)` 或弹簧单次轻微过冲（overshoot ≤ 1.05），禁止持续振荡 |
| 图标替换 | 交叉淡入 + 微缩放（1→1.15→1），150~200ms |
| 触觉反馈 | 完成态用 success 类型轻震，操作中不震（iOS UIImpactFeedbackGenerator / Android HapticFeedback，H5 降级为 vibrate API 且不可用时静默） |
| 手势类动画 | 一律跟手（位移与手指同步），松手后才交给动画收尾 |
| 降级 | 遵守系统"减弱动态效果"设置，reduced motion 时全部替换为直切；不支持的能力（震动/扩散）静默降级为普通过渡 |

## 平台实现锚点

参数相同，各端落地 API 不同，AI 实现时按此映射选型，**禁止凭空造 API**：

| 技术 | 实现锚点 |
|---|---|
| Android Compose | `spring()`/`tween()` + `animate*AsState`；下拉刷新用 NestedScroll 或 PullToRefresh；手势用 `Modifier.pointerInput` + `detectDragGestures`；转场用 `AnimatedContent`；侧滑返回优先系统 `PredictiveBack`；触觉用 `LocalHapticFeedback`；扩散用 `clipPath` |
| iOS SwiftUI | `withAnimation(.spring(response:damping:))`；大标题/返回手势优先 NavigationStack 原生；自定义手势 `.gesture(DragGesture())` + `matchedGeometryEffect`；触觉 `UIImpactFeedbackGenerator`/`UINotificationFeedbackGenerator`；图标交叉淡入 `contentTransition(.symbolEffect(.replace))`（iOS 17+） |
| H5 | 只动 `transform` 和 `opacity`（合成层属性），**禁用 top/left/width 触发重排**；跟手用 `requestAnimationFrame` + touch 事件；惯性速度用 touchend 前最后两帧差分估算；粒子/飞入用 Web Animations API；剪贴板 `navigator.clipboard` 需 https |
| 小程序 | 跟手类动画必须写在 **wxs** 里响应 touch（js 线程通信延迟高，写在 js 里必卡顿）；控件动效走 CSS，避免高频 setData 驱动动画；触觉 `wx.vibrateShort({type:'medium'})`；页面级转场用官方导航转场配置 |

**性能硬规则**：动画只操作合成层属性；长列表内做动画用 `will-change` 或平台等价物提升层，动画结束移除；交付前用开发者工具帧率面板过一遍目标机，连续掉帧的动效降级为直切。

## 无障碍硬规则

- 遵守系统减弱动态效果（`prefers-reduced-motion` / `UIAccessibility.isReduceMotionEnabled`），开启时全部直切
- 成功/失败/完成态**不能只靠颜色区分**（红绿盲）：必须叠加图标或文字（对勾/爱心填充/感叹号）
- 结果类反馈（已复制/已加入/已确认）用 `aria-live`/平台无障碍播报通知读屏用户，不能只有视觉气泡
- 手势类动效（侧滑返回/拖拽排序）必须保留等效的非手势路径（返回按钮/长按菜单）
- **长按确认/滑动确认必须提供替代路径**：无法完成 1.5s 长按或拖动的用户（运动障碍）给二次确认弹窗/点击确认作为等效操作
- 触控目标 ≥ 44×44pt；进度条类视觉信息（长按边框填充）同时给读屏可用等价描述

# A 部分 · 页面级交互动效八合一

## A1 卡片堆叠甩动（Tinder 式决策卡）

**动效表现**：最上层卡片跟随手指横向移动，拖动时向拖动方向倾斜；松手时若速度超过阈值则沿手势方向飞出，下方卡片顺势放大补位；未达到阈值则回弹至原位。

**何时不用**：非决策型内容（普通信息流/详情阅读）不用——没有"选下一个"的语义就是为动而动；桌面端大屏不适用（鼠标拖拽手感差）。

**物理参数基准**：倾斜角 = 横向位移 × 0.06，上限 ±12°；飞出速度阈值 ≈ 800px/s 或位移 > 卡宽 40%（二者满足其一即飞出）；飞出动画 300ms 渐隐；补位卡片从 scale 0.95 → 1，250ms 弹簧；回弹用 250ms 弹簧（单次轻微过冲）。

**AI 提示词**：
> 做一个可拖拽的卡片堆叠，顶部卡片根据横向位移旋转倾斜（倾斜系数0.06、上限12度）；松手时速度超过800px/s或位移超过卡宽40%就沿手势方向飞出并渐隐（300ms），下一张卡片从0.95放大到1补位（250ms弹簧）；没达到阈值就用弹簧动画回弹原位。

**边界情况**：只有一张卡时飞出后加载新内容再补位，不允许出现空堆叠；拖动中另一只手再次触控时忽略第二触点；连续快速甩卡时飞出动画可被打断（新卡立即接管）。

## A2 弹性下拉刷新

**动效表现**：列表下拉时拉动距离按阻尼衰减，越拉越费力；顶部刷新图标随下拉进度旋转；松手超过阈值触发加载，加载完成后内容用弹簧动画回弹归位。

**何时不用**：内容基本不变的工具页不用；已做无限滚动分页的列表可省（下拉刷新与上滑加载二选一，不叠加）。

**物理参数基准**：阻尼公式 `实际位移 = 1 - 1/(1 + 手指位移/240)`；触发阈值 = 下拉 64pt；图标旋转角 = 下拉进度 × 360°；回弹弹簧 stiffness ≈ 300、damping ≈ 26；未过阈值松手直接弹回。

**AI 提示词**：
> 给列表加一个弹性下拉刷新，拉动距离按阻尼衰减（公式1-1/(1+位移/240)），刷新图标的旋转角度跟随下拉进度；松手超过64pt就触发加载，完成后用弹簧动画回弹归位，未过阈值松手直接弹回。

**边界情况**：列表不在顶部时下拉不触发刷新；加载中再次下拉忽略；加载失败提示后仍回弹归位；刷新图标随进度旋转时禁止线性生硬跳变。

## A3 大标题滚动收缩

**动效表现**：页面顶部大标题随滚动距离连续变化，字号缩小、位置上移，滚动到阈值时收进顶部导航栏，导航栏背景同时从透明渐变成毛玻璃；反向滚动时标题放大恢复。

**何时不用**：内容不足一屏的页、无层级纵深的功能页（表单/设置/聊天）不用；列表页和详情页才值得用。

**物理参数基准**：收缩区间 = 滚动 0~72pt 连续插值（字号 28→17，不跳变）；毛玻璃透明度与滚动进度线性绑定；收进导航栏后小标题淡入 150ms；回滚恢复与收缩同参数反向。

**AI 提示词**：
> 页面顶部使用大标题，标题的字号（28→17）和位置跟随滚动距离在0~72pt内连续插值变化，滚到阈值时收进顶部导航栏，导航栏背景同时从透明渐变成毛玻璃；反向滚动时标题放大恢复。

**边界情况**：快速甩动滚动（fling）时动画不逐帧卡顿，直接按目标状态收敛；内容不足一屏时标题保持展开；iOS/Android 各用系统原生大标题组件优先，自绘时保持参数一致。

## A4 骨架屏扫光渐显

**动效表现**：数据加载时显示与真实布局一致的灰色骨架，骨架上有从左到右循环的渐变扫光；数据返回后内容和骨架交叉淡入，布局不发生跳动。

**何时不用**：接口稳定快于 300ms 不用（白闪一下比没有更难看）；纯本地数据不用；能整页缓存秒开的内容用缓存代替骨架。

**物理参数基准**：骨架块圆角、间距与真实内容完全一致（这是骨架屏的灵魂）；扫光周期 1.4s 循环，斜向 15°；交叉淡入 250ms；数据早于 300ms 返回时不显示骨架（避免闪烁）。

**AI 提示词**：
> 数据加载时显示和真实布局一致的骨架屏（圆角间距与真实内容一致），骨架上有从左到右循环的渐变扫光（周期1.4s）；数据返回后内容和骨架交叉淡入250ms，布局不发生跳动；数据300ms内返回就不显示骨架。

**边界情况**：加载失败时骨架停止扫光并显示重试按钮，而非永久转圈；分页加载只对新数据区显示骨架，旧内容保持不动；骨架期间禁止用户误触（可点击区域不响应）。

## A5 浮动标签与错误抖动

**动效表现**：输入框聚焦时，占位文字缩小上移成浮动标签；校验失败时输入框水平抖动两到三次，边框变红色，错误提示从下方淡入滑出。

**何时不用**：单一输入框且占位文字已足够说明时不用浮动标签；错误抖动只用于校验失败，禁止拿它做频繁提醒（滥用会让用户对抖动麻木）。

**物理参数基准**：标签上浮 150ms（字号 14→11，上移 10pt）；抖动 = 水平位移 ±6px 递减 ×3 次，总时长 300ms；错误提示淡入+上滑 180ms；修正错误后红色边框 150ms 渐隐恢复。

**AI 提示词**：
> 输入框聚焦时占位文字缩小上移成浮动标签（150ms）；校验失败时输入框水平抖动两到三次（±6px递减、总300ms），边框变成红色，错误提示从下方淡入滑出（180ms）；修正后红色边框渐隐恢复。

**边界情况**：输入过程中不实时校验（失焦或提交时才校验）；连续多次校验失败时抖动不叠加（正在抖就重置再抖）；错误提示出现时页面底部内容不被顶跳（提示预留高度或悬浮）。

## A6 拖拽排序

**动效表现**：长按列表条目后，条目放大到 1.03 并加深阴影；拖动经过时其他条目用弹簧动画让出位置，松手后条目吸附落入新位置。

**何时不用**：顺序无用户意义（按时间/相关性排）的列表不用；条目少且固定（≤3 项）用上移/下移按钮更省事。

**物理参数基准**：长按 350ms 激活（期间禁止滚动）；放大 1.03 + 阴影加深 120ms；让位动画 200ms 弹簧；吸附落位 250ms 弹簧（单次过冲）；激活时轻微触觉反馈（impact light）。

**AI 提示词**：
> 列表支持长按拖拽排序，长按350ms后条目放大到1.03并加深阴影、禁止滚动；拖动经过时其他条目用200ms弹簧动画让出位置，松手后条目250ms弹簧吸附落入新位置，激活时带触觉反馈。

**边界情况**：拖到列表边缘时自动滚动（auto-scroll），速度随贴近程度加快；拖动中来电/切后台则取消排序并落回原位；只有一项时不激活拖拽。

## A7 滑动删除加撤销

**动效表现**：列表项左滑时红色删除区跟随露出，滑动超过一半宽度自动删除，剩余条目平滑补位；底部弹出带撤销按钮的提示条，5 秒后自动消失。

**何时不用**：删除是重大且不可恢复的决策时改用确认弹窗（滑动删除适合高频轻量操作）；做不到真正撤销就别用这个动效。

**物理参数基准**：删除区露出宽度 ≤ 条目宽 30%，跟手无迟滞；过半阈值 = 条目宽 50%（或速度 > 600px/s）；删除动画 = 条目高度收拢 + 补位上移，250ms 弹簧；撤销条从底部滑入 200ms，5s 倒计时消失，点击撤销后条目原位滑回复原。

**AI 提示词**：
> 列表项支持左滑删除，红色删除区跟手露出（上限条目宽30%），滑动超过一半宽度或速度超过600px/s自动删除，条目高度收拢250ms弹簧、剩下的条目平滑补位；底部弹出带撤销按钮的提示条（200ms滑入），5秒后自动消失，点击撤销后条目原位滑回复原。

**边界情况**：删除进行中再滑其他条目需排队处理；撤销数据需真正恢复（含关联状态，不只视觉回来）；多条连续删除时撤销条只保留最近一条；系统杀进程后撤销失效属预期行为，不需恢复。

## A8 侧滑返回视差

**动效表现**：从屏幕左边缘右滑时，当前页跟随手指平移，上一页以三分之一的速度从左侧视差跟入，遮罩透明度随进度降低；松手时根据距离和速度决定完成返回还是回弹。

**何时不用**：Android 已提供预测性返回（Predictive Back）时优先系统原生，不自绘；一级页面（无可返回的上层）禁用。

**物理参数基准**：触发区 = 左边缘 20pt 内起手；上一页速度 = 当前页 × 1/3（视差比）；遮罩透明度 = 1 - 进度；完成条件 = 位移 > 屏宽 40% 或速度 > 1000px/s；完成收尾 200ms、回弹 250ms 弹簧。

**AI 提示词**：
> 做一个边缘右滑返回手势：从屏幕左边缘20pt内起手，当前页跟随手指平移，上一页以三分之一的速度从左侧视差跟入，遮罩透明度随进度降低；松手时位移超过屏宽40%或速度超过1000px/s就完成返回（200ms收尾），否则250ms弹簧回弹。

**边界情况**：页面内横向可滚动元素（轮播/表格）优先消费手势，边缘起手才触发返回；第一层级页面禁用；返回手势进行中按返回键/导航栏返回按钮需取消手势并直切；iOS 与 Android 各用系统原生返回手势优先，自绘时保持视差比一致。

## A 部分组合使用规则

- **下拉刷新 × 骨架屏**：分工不叠加——首次进页用骨架屏，之后刷新用下拉，同一区域不同时出现两种加载动效
- **拖拽排序 × 滑动删除**：拖拽激活期间禁用其他条目的滑动手势（同一手势竞争，同时响应必乱）
- **侧滑返回 × 大标题收缩**：同页共存时共用同一缓动与时长；返回手势起手区内的横向滚动不触发标题收缩联动
- **多动效同时触发**：排队执行（删除动画收尾后撤销条才入场），禁止同帧叠加；排队总时长超过 600ms 时后面的改为直切

# B 部分 · 控件级按钮交互六合一

让按钮有"真实手感和高级感"。核心方法：把按钮当**状态机**做，不做两态开关。

## 全状态自查（B 部分每个按钮必过）

| 状态 | 要求 |
|---|---|
| 初始 | 可按状态明确（颜色/阴影/禁用态区分清楚） |
| 操作中 | 按下即有反馈（scale/透明度 ≤ 120ms），手势类跟手 |
| 完成 | 明确的完成态变化（变色/图标替换/触觉反馈），不静默 |
| 恢复 | 自动复位或保持结果态可预期，复位动画不跳变 |

## B1 长按确认（危险/不可逆操作）

**交互表现**：按住按钮时，边框沿进度方向逐步填充；未填满松手，进度缓退清空；填满后按钮变为已确认状态，并触发轻微震动反馈。

**何时不用**：低风险或可撤销操作不用（点一下+toast 就够）；高频重复操作不用——每次都长按 1.5s 会把用户逼疯。只留给删除/支付/清空这类不可逆操作。

**物理参数基准**：按满时长 1.5s（线性进度）；SVG 圆环 `rotate(-90deg)` + `stroke-dasharray=周长`，按 `已过时间/1500ms` 更新 dashoffset；松手从当前值 **350ms 缓退归零（不是瞬间清零）**；走满后 shake 动画 → 变绿换对勾 → 触觉 success；监听必须挂 `window` 级 `mouseup/touchend`（手指可能滑出按钮），`mouseleave` 也终止。

**AI 提示词**：
> 做一个长按确认按钮：按住时沿边框填充进度（1.5s按满，SVG圆环stroke-dashoffset实现），未满松开则350ms缓退清空（不是瞬间归零），填满后shake一下变为已确认状态换成对勾图标，并触发轻微震动；监听挂在window级mouseup/touchend，手指滑出按钮也终止进度。

**边界情况**：按住后横向滑出即终止；动画结束必须复位状态机、支持反复触发；长按期间拦截页面滚动（`touch-action` / `preventDefault`）；系统返回手势与长按冲突时优先页面手势。

## B2 点赞迸发

**交互表现**：点击爱心图标后，图标弹性放大并变色，向外迸发一圈粒子效果，点赞数向上滚动加一。

**何时不用**：一屏十几个都带点赞的密集列表用轻量版（仅图标弹性+变色，不炸粒子），粒子只在单卡详情/大卡片用——否则满屏粒子互相遮挡，性能也崩。

**物理参数基准**：图标 `scale 1 → 0.8（25%处） → 1.25（60%处） → 1`（≈600ms），回弹曲线 `cubic-bezier(.34,1.56,.64,1)`，同步变色；8 个彩色小圆点以图标中心为圆心按 `2π/8` 均分角度（各加随机抖动）向外飞 34~60px、缩到 0.3 并淡出，动画 `onfinish` 移除节点；数字克隆节点做 `translateY(12px)→0` 上滚。**粒子只在激活（点赞）时炸，取消点赞不炸。**

**AI 提示词**：
> 做一个点赞按钮：点击后图标按scale 1→0.8→1.25→1弹性放大并变色（回弹曲线cubic-bezier(.34,1.56,.64,1)），向外迸发8个粒子（均分角度加随机抖动，飞散34~60px缩到0.3淡出，结束移除节点），点赞数向上滚动加一；取消点赞不炸粒子。

**边界情况**：快速连点要防抖或允许粒子叠加但数字只按真实次数走；动画结束必须清理粒子节点；点赞请求失败时乐观更新后回滚数字。

## B3 滑动确认（关键操作替代弹窗）

**交互表现**：拖动圆形滑块时，背景填充随滑块位置变化；滑到终点后变为对勾状态，中途松手则回弹到起点。

**何时不用**：非关键操作不用——普通确认按钮就够；仅用于误触发代价高的场景（接单/启动/解锁/大额转账发送）。

**物理参数基准**：滑块 100% 跟手；完成判定 = 位移 ≥ 95% 或速度 > 800px/s（快速一甩也能完成）；完成时滑块吸附终点 150ms → 变对勾 + 触觉 success；中途松手 250ms 弹簧回弹起点；填充宽度与滑块位置线性绑定。

**AI 提示词**：
> 做一个滑动确认按钮：拖动圆形滑块时背景填充随滑块位置线性变化，滑到终点（位移≥95%或速度>800px/s）滑块吸附终点变为对勾并轻微震动，中途松手250ms弹簧回弹到起点。

**边界情况**：锁定横向手势（竖向滑动仍交给页面滚动）；起点 8pt 死区防误触；完成动画播放期间忽略再次拖动；禁用态整条滑轨置灰且不响应。

## B4 加入购物车飞入

**交互表现**：点击按钮后，商品缩略图沿弧线飞入购物车图标，角标数字加一并弹跳反馈。

**何时不用**：页面无可见购物车图标时不用（没有飞行终点，降级为按钮自身完成反馈）；购物车入口在另一个 tab 时同样降级，硬飞跨页只会显得诡异。

**物理参数基准**：飞行 ≈500ms，二次贝塞尔弧线（控制点取起点终点中点上方偏移 15% 高度），同步缩放 1→0.2 + 渐隐（最后 30% 才淡出，全程看得见轨迹）；角标数字 +1 时 `scale 1→1.3→1` 弹跳 150ms；按钮本身按压反馈 100ms 先行。

**AI 提示词**：
> 做一个加入购物车按钮：点击后商品缩略图克隆一份沿二次贝塞尔弧线飞入购物车图标（500ms，控制点在中点上方15%高度，缩放1→0.2、最后30%才渐隐），角标数字加一并scale 1→1.3→1弹跳150ms。

**边界情况**：购物车图标不在视口内时降级为按钮自身完成反馈（图标变对勾）；连点合并：动画可叠加但加购请求去重防重复下单；克隆节点动画结束必须移除；列表滚动后目标坐标要实时取，不能缓存。

## B5 主题切换扩散

**交互表现**：点击太阳图标时，图标旋转变为月亮，页面配色以按钮为圆心向外扩散切换。

**何时不用**：只在主题切换是"仪式感时刻"的场景用（阅读/工具类 App 的主入口）；设置页里的普通开关用普通过渡即可，扩散动画每次设置都要看一遍就成了骚扰。

**物理参数基准**：图标旋转 180° + 交叉淡入 300ms；配色扩散用圆形揭示（`clip-path: circle()` 从 0 到覆盖全屏对角线长度，400ms，`cubic-bezier(.22,.8,.3,1)`），新旧两层页面分别渲染，扩散结束后移除旧层。

**AI 提示词**：
> 做一个主题切换按钮：点击时太阳图标旋转180度交叉淡入变为月亮（300ms），页面配色以按钮为圆心用clip-path circle()圆形扩散切换（400ms，半径从0到全屏对角线），扩散结束后移除旧配色层。

**边界情况**：H5/Safari 老版本不支持 clip-path 动画时降级为整页 200ms 淡切；扩散动画期间锁交互防连点；手动切换要记忆用户选择（覆盖跟随系统），下次启动沿用；深浅色 tokens 必须一次性整体切换，禁止逐个属性跳变。

## B6 复制反馈

**交互表现**：点击复制按钮后，图标变为对勾，上方浮出"已复制"提示气泡，两秒后自动恢复初始状态。

**何时不用**：一屏多处复制入口（代码块列表/多字段详情）可省气泡只做图标变化，避免气泡满天飞；气泡留给主要复制操作。

**物理参数基准**：图标交叉淡入换对勾 150ms（scale 1→1.15→1）；气泡从按钮上方 6pt 处淡入+上滑 150ms；2s 定时后 200ms 淡出恢复；恢复期间再次点击要能立刻重新触发。

**AI 提示词**：
> 做一个复制按钮：点击后图标交叉淡入变为对勾（150ms），上方浮出已复制提示气泡（150ms淡入上滑），两秒后气泡淡出、图标恢复初始状态；恢复期间再次点击要能立刻重新触发。

**边界情况**：连续点击重置计时器而非叠加多个气泡（同位置气泡复用）；剪贴板 API 失败（非 https/无权限）时气泡改报错文案；气泡不得遮挡关键内容，靠近屏幕顶部时改在下方浮出。

# 核心原则（两部分通用）

- **物理手感优先**：弹簧、阻尼、视差、回弹等自然运动规律，禁用生硬的线性动画；跟手阶段位移永远与手指同步；按压反馈必须在 120ms 内出现
- **全状态覆盖**（B 部分硬性）：初始 → 操作中 → 完成 → 恢复四态都有明确反馈，两态按钮就是没做完
- **动效服务于体验**：反馈清晰、操作路径明确，避免过度设计；一次只强调一个动效焦点；同屏活跃动效不超过两处
- **与业务深度结合**：参数可微调，但同一 App 内同类动效参数必须一致
- **可降级**：尊重系统减弱动态效果设置；低端机检测到掉帧时自动降级为直切
