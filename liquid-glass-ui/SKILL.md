# 液态玻璃界面生产工艺

核心认知：液态玻璃的美观度取决于**玻璃质感**与**背景选择**，两者缺一不可。玻璃层五步工艺负责"质感"，背景三原则负责"层次"——blur(28px) 会把背景细节平均化，能穿透玻璃活下来的只有大块形状和明暗对比。

## 一、五步玻璃工艺（必须严格执行，顺序不能乱）

1. **模糊**：`backdrop-filter: blur(28px)` — 出玻璃的朦胧底子
2. **增色**：`saturate(170%)` — 防止发灰暗淡。**最容易被漏掉的一步**，漏了玻璃就是"脏玻璃"
3. **叠白**：`background: rgb(255 255 255 / 10%)` — 通透底色，玻璃才不像一块挖空的洞
4. **亮边**：`box-shadow: inset 1px 1px #fff8` — 边缘高光带出厚度感；可加 `inset -1px -1px #ffffff14` 做右下弱光更立体
5. **折射**：SVG 位移滤镜让边缘轻微变形 — "液态"的灵魂，没有它只是毛玻璃：

```html
<svg width="0" height="0" style="position:absolute">
  <filter id="lens">
    <feTurbulence type="fractalNoise" baseFrequency="0.008 0.012" numOctaves="2" seed="5"/>
    <feDisplacementMap in="SourceGraphic" scale="16"/>
  </filter>
</svg>
```
```css
/* 写法顺序：先普通 blur 兜底，再追加折射（后者覆盖前者） */
.glass { backdrop-filter: blur(28px) saturate(170%); }
.glass { backdrop-filter: blur(28px) saturate(170%), url(#lens); }
```

输出代码时**必须逐条标注这五步对应的关键参数**。

## 二、叠白浓度随背景深度微调（实测结论）

| 背景明度 | 叠白浓度 | 说明 |
|---|---|---|
| 深色底（夜空/深海） | `rgb(255 255 255 / 8%)` | 白加多了发灰发白 |
| 中性/暖色底（沙丘/湖面） | `rgb(255 255 255 / 10%)` | 标准值 |
| 浅色底（云/雾） | `rgb(255 255 255 / 10%)` | 必须配合压暗层 |

## 三、背景三原则（必须严格执行）

1. **形状**：只用大块、柔和的形状（水面、云朵、沙丘、渐变、光带），拒绝细碎纹理
2. **配色**：主色控制在 1-2 种，拒绝多色杂乱
3. **明暗**：玻璃正下方压一层径向暗晕（约 `rgb(0 0 0 / 30-38%)`），保证文字可读——这是保险，不许省

推荐背景做法（全部验证过）：
- 光斑/雾团：大圆 + `filter: blur(60px)` + 缓慢位移动画
- 光带：长条圆角矩形渐变 + `mix-blend-mode: screen`（深色底极光效果）
- 分层：横向色带（如湖面水位线）制造前中后景

## 四、三禁令

- **禁细碎背景**：模糊后糊成一团，失去层次
- **禁纯色背景**：没有细节，玻璃只剩一个空框
- **禁杂色背景**：画面混乱，抢玻璃的视觉焦点

## 五、嵌套玻璃层次法则（玻璃里再叠玻璃时）

内层元素（按钮、小卡片、徽章）相对外层卡片：
- 叠白更淡：8% vs 外层 10%
- 亮边更细：单边 inset 即可
- 模糊更低：`blur(20px)` vs 外层 28px
- 内层略提亮：`rgb(255 255 255 / 14%)` 用于主操作按钮

## 六、兼容性（必须处理）

- **折射层 `url(#lens)` 只有 Chrome/Edge 支持**：必须先写普通 blur 兜底声明，再覆盖追加折射，Safari/Firefox 自动降级为高级毛玻璃
- 告知用户：完整"液态感"需 Chrome/Edge 查看

## 七、输出要求

1. 输出**完整可直接运行的单文件 HTML+CSS**（内嵌 SVG 滤镜与样式，不依赖外部资源）
2. 关键参数处加注释标注对应工艺步骤
3. 背景动画用 CSS 动画（光斑漂移 18-36s 交替），保持克制
4. 玻璃组件内文字用白色，配合压暗层保证对比度
